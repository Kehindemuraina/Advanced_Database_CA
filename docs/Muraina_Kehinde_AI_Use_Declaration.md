# Statement on the Use of Artificial Intelligence (AI)

In accordance with academic integrity and ethical guidelines, I declare that Generative AI tools were utilized in a supporting and assistive capacity for this project. All foundational system architecture, relational database design, schema definitions, and core implementations were conceived and authored independently.

AI assistance was strictly scoped to documentation, debugging, testing automation, database seed data generation, and document formatting as detailed below:

---

## 1. Tool-Specific Breakdown

### **Google Gemini**
- **Documentation & Fine-Tuning:** Assisted in drafting, refining, and polishing project documentation and explanatory write-ups.
- **Code Verification & Debugging:** Used for reviewing code to identify syntax errors, logical oversights, and debugging issues.
- **Testing Automation:** Scaffolded Bash test scripts used to automate test case execution and verify system behavior.
- **Database Seed Data Generation:** Assisted in generating synthetic seed and mock data to populate database tables for development, testing, and query validation.

### **Anthropic Claude**
- **Entity-Relationship Diagram (ERD):** Generated the visual ERD layout and diagram markup based on entity schemas and relational constraints that were previously analyzed and defined by the author.
- **PDF & Document Formatting:** Assisted in styling, formatting, and generating project deliverables in PDF format.

---

## 2. Author Verification and Accountability

The author retained full ownership of the intellectual and technical direction of this project. All AI-generated outputs—including documentation, test scripts, diagrams, and code suggestions—were critically reviewed, validated, and tested. The author assumes full responsibility for the accuracy, functionality, and academic integrity of the entire submission.
